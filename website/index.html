Features

Everything You Need to Ship Fast

Built for real-world software engineering, not toy demos.

🤖

Multi-Model Orchestration

Each agent uses the best model for its job. Gemini for planning, Claude for coding, GPT for testing. Swap models anytime.

🛠️

25 Built-in Tools

File read/write/edit, shell execution, git operations, web search, AST analysis, code analysis, test discovery, and shared memory.

🧠

Shared Working Memory

Agents pass context through a shared memory store. The planner's findings inform the builder. Test results guide the debugger.

🔄

Auto-Retry Pipeline

If tests fail, the debugger kicks in automatically. Build → Test → Debug → Rebuild cycles up to 3 retries until everything passes.

🔌

Plugin System

Extend haan.ai with custom tools, agents, and stages. Plugins load from .haan/plugins/ or npm packages.

🔗

MCP Integration

Works as both MCP server and client. Connect to Claude Code, VS Code, or consume external MCP tools like GitHub and databases.

⚡

Multi-Agent Collaboration

Complex tasks are decomposed into subtasks that run on parallel builder agents. DAG-based pipeline executes independent stages concurrently.

🖥️

Web Dashboard

Desktop-app-quality web interface with real-time streaming, split-panel layout, and live pipeline visualization. Run with haan --dashboard.

💰

Budget Controls

Set daily and per-task spending limits. Real-time cost tracking with per-model breakdown and automatic budget enforcement.

🔐

BYO API Keys

Use your own Anthropic, OpenAI, and Google API keys. Just drop them in a .env file — no accounts, no middlemen.

⚙️

Human & Auto Modes

Review each stage in human mode, or let it rip in full-auto. Control how much oversight you want per run.

💻

Rich Terminal UI

Ink-powered React terminal interface with live streaming, agent status, pipeline progress, and gradient styling.

Quick Start

Up and Running in 60 Seconds

1

Install

One command. Works on macOS, Linux, and Windows WSL.

curl -fsSL haan.ai/install.sh | bash
2

Configure

Add your API keys to the .env file. That's it.

nano ~/.haan/.env
3

Run

Give it a task in natural language. Watch the agents work.

haan "Add user auth"
4

Ship

Review the changes, commit, and deploy. Production-ready code.

git push origin main
